# ゲーム設定JSON

adminのゲームtab共通の「JSONを書き出す」で、保存済み設定を取得します。
未保存の編集、ユーザーごとのダンジョン母集団、進行、所持品は含みません。

形式は `tanbunism.game-settings`、versionは `1` です。

```json
{
  "format": "tanbunism.game-settings",
  "version": 1,
  "balance": { "base_hp": 70 }
}
```

- `catalog`: スキル、効果テンプレートと変型セット、アイテム、敵、
  ガンビットと変型セット、専門分野のスキル設定、習得設定、属性、ショップ。
- `balance`: ゲームバランス（初期能力値、敵計算式、成長、抽選、表示テンポなど）。
- `battle`: クイズ種類別の回答時間設定。

省略したセクション・項目は現状を維持します。catalogのリストは同じIDの定義を
更新し、未記載の既存定義を残します。配列の空指定も削除を意味しません。
更新対象の定義は全項目を持つ形式で記載し、書き出したファイルを編集するのが
確実です。ショップの照合キーはアイテムID、またはトリガーIDと変型IDです。
ファイルに記載した定義の並びを優先し、未記載分は末尾に残します。

「JSONを取り込む」は検証と差分確認までで、まだ保存しません。
「バックアップして反映」で変更前の全設定をダウンロードし、全セクションを
同一トランザクションで保存します。確認中に設定が変わっていれば再確認が必要です。
反映時には各タブの未保存の編集を破棄して、保存済み設定を再読み込みします。

バックアップの再取り込みでも未記載の定義は削除されないため、取り込み後に
新規追加した定義の削除まで自動で巻き戻す「完全復元」ではありません。
既存の `tanbunism.skills` 形式のファイルも、同じ取り込み口で利用できます。

## CLIからAPI経由で操作する

CLIもWeb版と同じ管理者APIを利用し、DBへ直接接続しません。
接続先は既存の `KNOWDE_URL`、認証は `tb user` の保存済みトークンを使います。
管理者でない場合は反映できません。

```sh
# 本番用のディレクトリへ移動して実行する。
# このリポジトリ内では.envrcがローカルAPIを指定するので、.envrc自体は変更しない。
cd /tmp
tb user google-sso --no-browser

# 保存済みの設定を書き出す。既存ファイルは上書きしない。
tb game export -o current-game-settings.json

# APIで検証して変更セクションを表示するだけ。DBもファイルも変更しない。
tb game import updated-game-settings.json --dry-run

# 確認後に変更前バックアップを作り、一括反映して再取得でも確認する。
tb game import updated-game-settings.json
```

各コマンドは接続先を表示します。`KNOWDE_URL` が未指定なら既定の本番APIを使います。
別サーバー用に保存した認証情報は送らず、ログインし直すよう案内します。
旧バージョンで保存した接続先情報のない認証も読み込めますが、安全のため再ログインを推奨します。

`--backup before.json` でバックアップ先を指定できます。省略時は入力ファイルと同じ
ディレクトリに、時刻と識別子付きのバックアップを作ります。
バックアップできなければ反映しません。`--yes` は確認だけを省略し、バックアップは省略しません。
競合や反映要求のタイムアウトでは勝手に再送しないため、`export` で状態を確認してください。

## SSH越しのGoogle SSO

`tb user google-sso --no-browser` で表示されたGoogle認証URLを手元のブラウザで開きます。
認証後に返る `access_token` と `token_type` を含むJSONを、SSH先の端末へ1行で
貼り付けてください。貼り付けた内容は表示せず、APIで有効性を確認してから保存します。
手元のブラウザへトークンを送り返すローカルHTTPサーバーは使わないので、ポート転送は不要です。

複数行のJSONはSSH先で権限を制限した一時ファイルに保存し、次のようにも利用できます。

```sh
tb user google-sso --token-file /path/to/login-result.json
```

ログイン結果ファイルは機密情報です。不要になったら削除し、チャットやGitへ貼らないでください。
CLIの認証設定ファイルは所有者だけが読み書きできる権限で保存し、`tb config` でも
アクセストークンは伏せて表示します。
