# 専門分野・ガンビットの実装方針

2026-10-16 の対話で決定。過去の「通常クイズの正解でガンビット発動」を置き換える。

## 現行方針への更新（2026-10-18）

以下は2026-10-16の方針からの変更点。後段の旧記録と異なる場合はこちらを優先する。

- 行動キュー方式では、直接スキルのガンビットはプレイヤーの通常行動を置き換える。実行できるものがなければ、最下位の固定ガンビット「戦う」（反撃・物理・敵1体・MPと枠の消費なし）を使う。
- 管理画面は回復・物理攻撃・特殊攻撃・バフ・デバフ・状態異常の表に分ける。歩数回復・装備効果は「その他」に残す。各入力は1列1項目。
- 失敗時の挙動はスキルの `on_wrong` に持つ。反撃は攻撃のみ、不発は効果なし、軽減は正答時と誤答時の効果量を独立指定する。対象・指定方式・演出・持続・重複上限は共通。
- 状態異常の正答時は付与、軽減タイプの誤答時は付与する／しない。確率や追加の成功判定は設けない。
- 1行動のクイズは1問。専門分野も配合した元リソース群から1リソースをランダムに選び、その作成済みクイズから1問出す。進行中の旧複数問スナップショットだけ旧精算を維持する。
- 誤答時倍率の設定は利用設定から取り除き、スキル定義の正誤効果に統合する。保存済みの旧設定は読み取り時に移行し、明示済みの `on_wrong` は上書きしない。
- 物理は攻・守、特殊は特攻・特守を使う。特攻・特守の初期値とポイント上昇量はadminで設定する。旧敵の特攻は元の攻撃力、特守は0として互換復元する。

## 旧方針の記録（2026-10-16）

- ガンビットはキャラ単位の優先リスト。通常戦闘のターン終了後、生存していれば実行可能な最初の1行を自動実行。通常クイズの正誤には依存しない。
- 通常敵に追加クイズは付けない。仲間・ボス専用クイズ・マス目と自動移動は今回の対象外。
- アイテムはスキル定義を参照。スキルは回復・攻撃・buff・debuff・状態異常ごとの表で編集。
- 専門分野は達成度5のボス撃破で作成可能。リソースにつき一度のみ作成し、未装備でも保持。
- 装備枠は初期1、Lv20ごとに1追加。間隔はadmin設定。ガンビットのルール枠とは別。
- 作成時にadminの「スキル利用」で専門分野向けに登録されたスキルを1つ選ぶ。
- 配合は2つを1つに置き換え、元のリソース集合を統合。元のどちらかのスキルだけ残す。元の専門分野は再作成不可。
- 効果量は `基礎値 + 係数 × log(1 + 元リソースの合計Power)`。最新Powerを発動時に反映し、配合順には依存しない。持続ターン・消費MPは固定。
- ガンビットには装備中の専門分野を指定できる。未装備・不足MPなどの場合は次の行へ。
- 専門分野クイズは各元リソースの作成済みクイズから1問ずつ。配合元が2つなら2問。1問ごとに通常戦闘とは別の制限時間を開始し、秒数はadmin設定。
- MP/アイテムは1行動につき一度だけ消費。回答済み問題は再回答不可。時間切れは誤答。
- 数値効果は `誤答倍率 + (1 - 誤答倍率) × 正答率` を1回分の効果量に掛ける。状態付与は付与/不付与のみ。
- バブルは最大HPと残HPの両方に倍率を適用。解除時も両方を同率で戻す。戦闘終了時に解除。

## 単純な仮ルール

- 状態付与は専用クイズがある場合、全問正解で付与。確率・追加の成功閾値は設けない。
- 戦闘終了・敗北・撤退時には追加のガンビットは実行しない。
- 専門分野の装備・作成・配合は戦闘外のみ。配合で装備は外れ、ガンビットの旧参照は使用不能として表示。
- 配合・作成の取り消し、能力別の複雑なPower式、敵の自動移動は実装しない。

## スキル定義と利用設定の分離（2026-10-16）

- スキル本体は効果・対象・効果量・消費MP・持続・重複上限・演出のみを持つ。
- 直接使用可・専門分野専用というフラグは廃止。プレイヤー用のスキル一覧と専門分野用の利用設定がスキルIDを参照する。
- 専用クイズの有無・秒数・誤答時倍率・Power係数は専門分野の利用設定に置く。アイテムと敵のスキル参照は既存の各定義に置く。
- 旧カタログは読み込み時にフラグから利用設定を導出する。明示的な空一覧は空のまま保ち、次回保存で旧フィールドは保存しない。
- adminの効果表は1列1項目とし、種類ごとに追加ボタンと効果候補を限定する。異なる種類への変更は行わず、その種類の表で追加する。
- 演出は許可リストのプリセットのみ。プレビューと実戦・模擬戦で共用し、戦闘処理の待ち時間を増やさない。動きを減らす設定では非表示にする。
