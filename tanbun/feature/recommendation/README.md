# 日替わり推薦

- 日本時間の午前0時を境界に、ユーザー・用途ごとの推薦IDを保存する。
- 同日は順序を維持する。「見たよ」や回答状況は取得時の最新値を返す。
- Resourceごとに重み付き抽選し、各Resourceから交互に選ぶ。
- 単文は未遭遇、累計閲覧の少なさ、最後の閲覧からの経過日数を重視する。
  分散した最大150件の候補の位置・スコアを取得し、スコアも抽選の重みにする。
- クイズは最新分だけでなく既存の有効クイズ全体を対象にする。
  未回答・直近不正解・低正答率を優先し、最近の正解は控える。
- 個人クイズと全ユーザー版のセットは別々に保持する。推薦時に生成はしない。
- 削除・参照切れ・所有権変更によって無効になった項目は復元時に除外する。
  同日の補充はしない。ただし空セットは初回インポート・クイズ作成後に再選択できる。
- 保存ノードはユーザー・用途ごとに1件を翌日置き換える。ユーザー削除時にも削除する。

候補の抽選は日付・ユーザー・項目IDのハッシュを利用し、アクセスごとのランダムな
並び替えはしない。日替わりセットは初回取得時に保存するため、その日の新規追加は
原則翌日の候補になる。

## 復習設定

復習画面で既存StudyPlanを選ぶと、知識・クイズの両タブで対象を共有する。
知識APIの `profile=plan:{UUID}` は本人のPlanの対象Resourceから推薦し、
別の復習設定やStudyPlanを複製しない。知識は既定30件・バランス方針を使う。
クイズは既存のStudyPlan推薦を使い、Planの形式・問題数を維持する。
プロフィールの所有リソースからは `/review?resource={UUID}` で開始し、
該当する単一リソースPlanを優先する。見つからなければ別のPlanへ切り替えない。

`/review/settings` は本人の標準・自作設定のCRUDを提供する。
対象は本人の全リソース、または選択した所有リソース。単文とクイズの件数は
独立した上限（各1〜100）で、候補が不足してもクイズを生成しない。

- `balanced`: 未接触・未回答、間隔、スコア／正答率を混ぜる。
- `unseen`: 未接触・未回答の抽選重みをさらに上げる。
- `weak`: クイズは不正解・低正答率、単文は接触回数と間隔を重視する。
- `score`: 対象単文のスコアを重視する。高コストなスコア計算は最大150候補。

いずれもResourceを分散した重み付き抽選であり、厳密な順位順ではない。
初回の復習時に `ReviewDaySettings` に適用設定を保存し、知識・クイズで共有する。
設定を編集しても開始済みの今日のセットは変わらず、翌日から反映する。
`POST /review/settings/{id}/rebuild` のみ、その設定のスナップショットと推薦セットを
破棄する。閲覧・回答・XPの記録は消さない。

消化後の追加復習は `POST /dashboard/tanbuns/more` と `POST /quiz/daily/more`。
適用済みの設定から追加候補を選び、既存順序を保持し、同日のIDを重複追加しない。
追加分を含めて各セットは最大500件まで。設定ごとの保存ノードは翌日置き換え、
設定削除・アカウント削除時に関連ノードも削除する。
