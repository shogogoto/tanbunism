# 日替わり推薦

- 日本時間の午前0時を境界に、ユーザー・用途ごとの推薦IDを保存する。
- 同日は順序を維持する。「見たよ」や回答状況は取得時の最新値を返す。
- Resourceごとに重み付き抽選し、各Resourceから交互に選ぶ。
- 単文は未遭遇、累計閲覧の少なさ、最後の閲覧からの経過日数を重視する。
  分散した最大150件の候補の位置・スコアを取得し、スコアも抽選の重みにする。
- クイズは最新分だけでなく既存の有効クイズ全体を対象にする。
  未回答・直近不正解・低正答率を優先し、最近の正解は控える。
- 個人クイズと全ユーザー版のセットは別々に保持する。推薦時に生成はしない。
- 削除・参照切れ・所有権変更によって無効になった項目は復元時に除外する。
  同日の補充はしない。ただし空セットは初回インポート・クイズ作成後に再選択できる。
- 保存ノードはユーザー・用途ごとに1件を翌日置き換える。ユーザー削除時にも削除する。

候補の抽選は日付・ユーザー・項目IDのハッシュを利用し、アクセスごとのランダムな
並び替えはしない。日替わりセットは初回取得時に保存するため、その日の新規追加は
原則翌日の候補になる。
